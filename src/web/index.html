CV draft

    
Edit the CV text, then select Check. Every line needs a marker such as [pk:ID]. Print works only after a check with no errors. Warnings do not stop printing, so read each one. A line marked [pk:self] is your own statement and is not checked.

    
    
 

    
    
  
    
  
    
    
    Your data
    
    
    Your records are on this computer, in this folder:
    
    
    
    
    The app keeps no record data in browser storage. The browser keeps only the session key for this tab. It forgets the key when you close the tab.
    
    
    Backup
    
    
      
      
    • Select Export to save all your records in one file. The file holds private records too. Keep it private.
      • 
      
    • Or make the store folder a private git repository and push it to a private remote that you control.
      • 
      
    • To restore an export on a new computer, run personakit import archive FILE. Restore in the app comes later.
      • 
    
    
    
    
    
    
      
    
      
     
    
    
    
    
    Safety
    
    
    The app runs only on this computer. A secret key in the URL and checks of the Host and Origin headers stop other web pages from reading your records. The token and the host checks are a safeguard, not a security boundary. Programs that run as your user can read the store files.

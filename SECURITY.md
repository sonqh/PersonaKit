# Security policy

PersonaKit handles personal information. Report a security problem privately.

## How to report

1. Open the [Security tab](https://github.com/sonqh/personakit/security) of this repository.
2. Select **Report a vulnerability**.
3. Describe the problem in the private form.

Do not open a public issue for a private-data exposure. A public issue can expose the data again.

## What to include

- What you tried to do.
- What data appeared where it should not.
- Steps to reproduce the problem with synthetic data.
- The app version or commit, browser, and operating system.

Do not send real CVs, real personal records, credentials, or API keys. Replace them with fictional examples.
